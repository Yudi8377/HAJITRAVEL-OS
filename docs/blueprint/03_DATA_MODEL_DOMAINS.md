# Master Data Model Domains

Identity: organizations, branches, users, roles, capabilities, user_scopes, sessions, devices.

CRM: customers, pilgrim_profiles, family_units, family_delegations, leads, inquiries, conversations, quotes, bookings, preferences, complaints, reviews.

Journey: journeys, departures, groups, group_members, itineraries, journey_events, meeting_points, checkpoints, assignments, state transitions.

Travel: flights, segments, pnrs, tickets, seats, baggage, hotels, allocations, rooms, transport_units, drivers, routes, transport_events.

Documents: documents, versions, verifications, permits, permit_events, insurance_policies.

Safety/Health: location_consents, location_events, geofences, proximity_events, alerts, incidents, response_assignments, emergency_contacts, sos_events, health_consents, profiles, wearable_connections, observations, health_alerts.

Finance/Procurement/Compliance/AI/Governance domains are defined in the master blueprint ZIP and are designed around organization scope, lifecycle state and auditability.
