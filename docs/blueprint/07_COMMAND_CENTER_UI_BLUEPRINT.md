# Command Center & Premium UX

Executive Command Center: revenue, bookings, cash, receivables/payables, margin, departure readiness, critical incidents, compliance exceptions, supplier risk, AI briefing and forecasts.

Operations Command Center: journey state, departure readiness, travel exceptions, groups, incidents and safety alerts.

Incident Room: incident ID, severity, pilgrim/group, authorized last-known location, timeline, actions, responders, communications, evidence, resolution and lessons learned.

UX should be calm, context-rich and operationally focused, with timeline/map/status/next action patterns and explicit loading/error/empty/offline states.
