# HAJITRAVEL Pilgrim Android App

Aplikasi pendamping jamaah HAJITRAVEL OS: beranda perjalanan, readiness, timeline, Digital Pilgrim ID QR, keluarga/guardian, consent, bantuan, mode offline minimum dan secure device session.

Digital Pilgrim ID adalah credential internal HAJITRAVEL, bukan paspor, visa, boarding pass, credential pemerintah atau maskapai. Health hanya operational signal, bukan diagnosis. Location sharing wajib consent, purpose, time-bound dan role-based serta diaudit.
